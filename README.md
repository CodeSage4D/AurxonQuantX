## Phase 0 Environment Audit Summary

- **OS:** Linux Mint 22.3 (Ubuntu 24.04 noble base), Linux 7.0.0 kernel x86_64
- **Host Memory:** 7.5 GiB RAM (~2.5 GiB available) $\to$ *Strict budget: Large local LLMs (7B+) are avoided in-memory to prevent system thrashing; lightweight compact models and remote cloud providers used instead.*
- **Accelerators:** CPU compute only (no discrete NVIDIA GPU).
- **Toolchains Verified:**
  - Python 3.12.3 in dedicated `.venv`
  - Node.js v20.20.2 & npm 10.8.2
  - Git 2.43.0
  - Tesseract OCR v5 (/usr/bin/tesseract)
  - SQLite 3.45.1
- **Trading Safety:** Real-money execution hard-locked (`ENABLE_REAL_TRADING=false`). Paper trading & research mode only.

## Verification & Automated Test Suite

All 18 unit, integration, and API tests execute synchronously and pass cleanly:

```bash
# Activate virtual environment
source .venv/bin/activate

# Run full backend test suite
PYTHONPATH=backend pytest backend/tests -v
```

### Coverage:
1. `backend/tests/test_valuation.py`: Graham Number, 2-Stage DCF, Piotroski 9-point score, Altman Z-Score, Sharpe/Sortino/Drawdown risk metrics.
2. `backend/tests/test_evidence_loop.py`: 10-step Evidence-Loop workflow, event streaming, contradiction detection, and audit ledger persistence.
3. `backend/tests/test_nse_connector.py`: Symbol normalization and offline benchmark fixtures.
4. `backend/tests/test_screen_ocr.py`: Symbol extraction and regex privacy redactor for OTPs/credentials.
5. `backend/tests/test_api_endpoints.py`: FastAPI endpoints (`/health`, `/market/quote`, `/research/sync`, `/audit/records`, `/companion/context`).

## How to Run the Platform

### 1. Start Backend Server
```bash
source .venv/bin/activate
PYTHONPATH=backend uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```
API Documentation is available interactively at: `http://127.0.0.1:8000/docs`

### 2. Start Desktop Frontend UI
```bash
cd frontend
npm run dev
```
Open `http://127.0.0.1:5173` in your browser or desktop webview.

### 3. Production Frontend Bundle
```bash
cd frontend
npm run build
```

## Safety & Ethics Principles
1. **Never Hallucinate Ratios:** Financial multiples (P/E, P/B, DCF, Graham, Piotroski) are calculated deterministically in Python using pure math—never generated by an LLM.
2. **Auditable Evidence:** All material claims link to verified exchange filings or disclosure sources with timestamped audit IDs.
3. **Zero Credential Harvesting:** The screen companion and browser extension automatically redact OTPs, passwords, and banking identifiers. Real-money orders cannot be triggered.
